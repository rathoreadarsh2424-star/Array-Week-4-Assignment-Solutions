# Array Week 4 — Category C Assignment (Java)

Solutions to the five problems in `Array_Week4_Category_C_Assignment_Problem.pdf`.

| File | Algorithm | Time | Extra space |
|---|---|---|---|
| Problem1ProductExceptSelf.java | Prefix and suffix products, no division | O(n) | O(1) excluding output |
| Problem2MaximumSubarray.java | Kadane’s algorithm | O(n) | O(1) |
| Problem3ThreeSum.java | Sort + two pointers + duplicate skipping | O(n²) | O(n) for sorting/output as applicable |
| Problem4SubarraySumEqualsK.java | Prefix sum frequency map | O(n) average | O(n) |
| Problem5FindMinimumRotatedArray.java | Modified binary search | O(log n) | O(1) |

## Run

From `src/`, compile all with `javac *.java`. Run each separately, e.g. `java Problem1ProductExceptSelf`. Each main method prints the sample outputs in the PDF. Java 8+.
